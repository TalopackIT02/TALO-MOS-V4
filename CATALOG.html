Chạy thử WebApp

Trạng thái hiện tại: Chưa thể chạy npm run dev: frontend/backend vẫn là placeholder, chưa có script dev, source và dependencies. Các nút không tự chạy lệnh trên máy tính của bạn.

Windows: Giải nén ZIP, mở thư mục TALO-MOS-V4 rồi nhấp đúp run-dev.cmd; script kiểm tra và thông báo phần còn thiếu. Linux/macOS: mở terminal tại root và chạy bash run-dev.sh.

Sau khi Claude Code tạo ứng dụng thực, thêm dev scripts vào từng package.json và cài dependencies. Khi đó launcher mới có thể khởi chạy hai dịch vụ. Bạn cũng có thể copy lệnh riêng cho frontend/backend để chạy trong terminal.
