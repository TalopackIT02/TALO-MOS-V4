## Status vocabulary
- `USER_MANDATED`: the User requested the technology or strict constraint.
- `CLAUDE_PROPOSED`: Claude's suggestion; not approved.
- `USER_APPROVED`: User explicitly approved a choice.
- `CLAUDE_IMPLEMENTED`: implementation was observed after approval; never an approval class.
- `PENDING`, `REJECTED`, `DEFERRED`: decision statuses.

**Important:** Origin, approval, implementation and evidence are distinct fields; don't collapse them into a single status.
